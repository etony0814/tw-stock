# 台股五方綜合決策（網頁版 / GitHub Pages）

純前端、免後端、免 API key 的台股買賣決策輔助工具。一次整合 **5 個面向**：

| 面向 | 說明 | 資料來源（瀏覽器直抓，免金鑰） |
|------|------|-------------------------------|
| 技術面 | SMA、MACD、RSI、KDJ、布林、乖離等訊號 | Yahoo 台股日K（`2330.TW`） |
| 籌碼面 | 外資／三大法人買賣超 | TWSE 官方 T86 端點 |
| 盤面 | 當天開盤、現價、漲跌、量比、均線位置 | Yahoo 日K |
| 大盤 | 加權指數當日多空＋個股相對強度 | Yahoo `^TWII` |
| 消息面 | 近 N 天新聞情緒（關鍵字） | Google News RSS |

五方用權重（技術 40%、其餘各 15%）折成一個「今天要不要買賣」的白話結論。

> ⚠️ 本工具僅供學習研究，**不構成投資建議**。股市有風險。

## 部署到 GitHub Pages

1. 建立一個 GitHub 倉庫（例如 `tw-stock`）。
2. 把這個 `deploy` 資料夾裡的 2 個檔案放到**分支根目錄**（或 `docs/` 根目錄）：
   - `index.html`
   - `core.js`
3. 開 **Settings → Pages**：
   - 若放分支根目錄 → Source 選 **Deploy from a branch**、Branch 選 `main`、Folder 選 `/ (root)`。
   - 若放 `docs/` → Branch 選 `main`、Folder 選 `/docs`。
   - 存檔。
4. 稍等 1~2 分鐘，網址 `https://你的帳號.github.io/tw-stock/` 就會開。

## 手機使用

介面已支援手機（RWD）。在手機瀏覽器開上面的連結即可，或掃 QR。

## 說明與限制

- **上線（`https://你的帳號.github.io`）是安全來源**，瀏覽器可直抓 Yahoo / TWSE / Google News，會拿到**真實資料**。
- 若在**本地（非 https）環境**直抓被 CORS 擋，會自動走跨域代理；都失敗時顯示「示範資料」以展示介面，並明確標註。
- Yahoo 偶有速率限制（429）；換時間或重試通常會恢復。
- 籌碼面採「當日全場法人最活躍榜單」判斷全市場方向；目標股若未進榜會特別標註「該股法人淨額相對不大」。

## 檔案結構

```
index.html   # 前端介面（手機 RWD + 五方決策卡）
core.js      # 共用核心：指標、訊號、五方綜合、籌碼、盤面、大盤、消息
```

## 想同步修改（與電腦版共用 core.js）

所有指標／訊號／五方綜合的邏輯都在 `core.js`。電腦版（`server.py` + `ui.html`）與
此 GitHub 版共用同一套規則；改 `core.js` 兩版同時生效。UI 文字與版面則各改各的 HTML。
